# Banking System GUI

This is a simple banking system implemented in Python using Tkinter.  
It demonstrates:

- Object-Oriented Programming (OOP) concepts: abstraction, inheritance, encapsulation, polymorphism  
- Abstract classes with `Account`  
- A `SavingsAccount` class implementing deposit, withdraw, and balance methods  
- GUI for user interaction: deposit, withdraw, and view balance  

## How to Run

1. Clone the repo  
2. Run `python banking-system.py` 
3. Enter your name and starting balance  
4. Deposit and withdraw money using the GUI
